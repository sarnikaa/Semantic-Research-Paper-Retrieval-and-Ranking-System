# Abstract

## Semantic Research Paper Retrieval and Ranking System

### Introduction
The exponential expansion of academic publishing has intensified the challenge of literature discovery. Conventional scholarly search engines depend primarily on lexical matching models such as Okapi BM25 and TF-IDF. While computationally efficient, these algorithms suffer from the fundamental vocabulary mismatch problem: papers addressing identical conceptual topics frequently employ differing terminologies, rendering lexical recall inadequate for paraphrased, exploratory, or interdisciplinary queries. Conversely, papers featuring high term overlap without genuine conceptual relevance are routinely over-ranked. Compounding this challenge, researchers face considerable cognitive overhead in parsing dense, technical abstracts to determine relevance. Modern information retrieval systems must therefore integrate semantic representation, multi-stage re-ranking, structural citation authority, and rapid, grounded result interpretation.

### Objective
This project designs and evaluates an end-to-end Semantic Research Paper Retrieval and Ranking System that overcomes lexical constraints through deep semantic matching and contextual assistance. Specifically, the system aims to: (1) construct a high-recall dual-index retrieval pipeline combining sparse lexical search with dense vector embeddings, (2) apply parameter-tuned reciprocal rank fusion followed by a cross-encoder neural re-ranker to maximize top-k precision, (3) synthesize content relevance with citation network authority and publication recency via calibrated score normalization, (4) incorporate a locally hosted, privacy-preserving Large Language Model (via Ollama) for on-demand, hallucination-resistant paper explanations, and (5) empirically validate ranking improvements against standardized IR benchmarks.

### Dataset Overview
The system employs a dual-track data strategy to ensure both practical scalability and rigorous empirical validation. For interactive deployment, the primary corpus is derived from the **arXiv Metadata Dataset**, filtered to Computer Science domains (Information Retrieval `cs.IR`, Computation and Language `cs.CL`, and Machine Learning `cs.LG`), yielding approximately 200,000 papers with citation links enriched via the **Semantic Scholar Academic Graph API**. For formal, reproducible evaluation, the system utilizes the standardized **SciFact** and **SCIDOCS** datasets from the **BEIR (Benchmarking Information Retrieval)** framework, which supply real-world scientific queries paired with expert human-annotated relevance judgments (qrels).

### Libraries, Methods, and Algorithms to be Used
The system is built on a modular multi-stage architecture:
1. **First-Stage Candidate Retrieval:** Lexical indexing is implemented using `rank-bm25`. Concurrently, dense semantic document representations are generated from paper titles and abstracts using scientific transformer encoders (`sentence-transformers`, comparing `all-MiniLM-L6-v2` and `BAAI/bge-small-en-v1.5`). High-dimensional embeddings are indexed using **FAISS** (`IndexFlatIP`) for accelerated cosine similarity search.
2. **Hybrid Fusion, Re-Ranking, and Calibration:** Candidate rankings from lexical and dense retrievers are merged using **Reciprocal Rank Fusion (RRF)**. Systematic parameter tuning identifies $k=10$ as optimal. The top candidates are re-scored by a joint cross-attention **Cross-Encoder** (`ms-marco-MiniLM-L-6-v2`). To prevent score domination, neural scores, graph-based **PageRank** centrality (computed via `networkx`), and an exponential temporal recency decay function are individually normalized via Min-Max scaling before computing the final composite ranking score.
3. **Local Grounded Synthesis Layer:** A locally hosted LLM served via **Ollama** (`llama3.2:3b`) is integrated to generate on-demand abstractive summaries, query-conditioned relevance rationales, and hypothetical document expansions (HyDE). Prompts are strictly constrained to the retrieved abstract text to ensure factual faithfulness with zero external API dependencies.

### Expected Result
The hybrid retrieval and re-ranking pipeline is expected to demonstrate clear improvements over the standard Okapi BM25 baseline on conceptual and paraphrased queries, with substantial, statistically verified gains observed on the SciFact benchmark (reaching nDCG@10 = 0.6989 and Recall@100 = 0.9577, $p < 0.01$). In alignment with published literature, gains on SCIDOCS are expected to remain more modest, reflecting the notorious resilience of lexical baselines on dense co-citation tasks. Additionally, the local LLM explanation module is expected to provide concise, hallucination-free paper relevance justifications, significantly expediting the literature triage process for researchers.
